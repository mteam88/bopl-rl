# Own-kit lineups: every specialist on its own three abilities, against every
# other specialist on theirs. Generated from league/league.json by
# `league play --own-kit`, which regenerates it and refuses to run if it
# disagrees with the league, so a membership change cannot leave a stale file
# describing a condition it no longer matches.
#
# Two rows per unordered pair, [A|B] and [B|A], because a loadout row fixes the
# kit each SEAT plays, not the kit each participant plays. Pinning one
# asymmetric row per pair and swapping sides under it - which is what
# elo_ladder.pair_tasks does - hands each specialist its opponent's kit in
# exactly half its games and reports the blend as a clean number. The schedule
# pairs row [A|B] with side 0 and row [B|A] with side 1, so the participant
# whose kit comes first always plays player 0, and side balance comes from
# alternating the row instead of swapping seats. Requires --mirror-share 0,
# unlike lineups-8.txt which is deliberately mirrored.
#
# `random` has no kit of its own and takes its opponent's, which keeps the
# opponent on its own kit and makes the anchor kit-matched. Bradley-Terry has
# no scale without `random` in the condition, so excluding it would leave this
# matrix unratable.
#
# 9 members -> 36 pairs -> 72 rows.
