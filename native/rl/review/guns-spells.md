## Summary

**47 confirmed and 21 suspected divergences** across the 16 abilities, plus five places where `FULL_COMPATIBILITY.md` / `ability-coverage.json` / `rl/ABILITY_PORT_GAPS.md` assert fidelity that does not hold. The most consequential is that **duplicated platforms are never superseded or destroyed in the Rust port**: C# `DuplicatePlatformEffect.cs:310-311` calls `DetPhysics.DeleteObjectFromDuplicateListWithId(hierarchyNumberOfGunTransform, 20)` before each `DuplicateObject(..., allowOnlyASingleCopyWithInifinteLifespan: true, ...)`, capping each Duplicator gun at one permanent duplicated platform (the previous dies 80 ticks later), whereas `spawn_duplicate_platform` (mod.rs:21947-22011) only pushes and `duplicated_objects_tick` has no platform loop. An RL agent accumulates unbounded permanent map geometry from the second platform duplication onward — the map itself diverges, and everything downstream with it. Runner-up: the Rust models Time Stop as a global `updater_dt` multiplier, but C# scales time **per-updatable, opt-in** via `GameTime.FixedDeltaTime`; `Updater.cs:302` passes raw `deltaTime` to every `UpdateSim`. That is a whole-model error, not a single bug.
